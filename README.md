# RedCat Twitch Miner 2.0

Personal Twitch Channel Points / Drops miner configuration and extensions for two EVE Online channels.

Target channels:
- `v_craken_v`
- `fenriscreations`

Initial scope:
- Channel Points
- Twitch Drops
- Moments
- Watch Streaks
- Raids
- Session and persistent points statistics
- Graceful shutdown after a raid when both target channels remain offline

Upstream engine: `Guliveer/twitch-miner-go`
